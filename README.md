# Mohammad Yahia - Personal Website

Minimal Astro personal site for GitHub Pages with:

- Home page
- CV page with PDF download
- Blog written in Markdown
- Tag pages
- Light and dark theme toggle

## Local development

```powershell
npm install
npm run dev
```

Typical local URL:

- `http://localhost:4321`

## Build

```powershell
npm run build
npm run preview
```

## Content locations

- Profile data: `src/data/profile.ts`
- Blog posts: `src/content/blog/*.md`
- Photo: `src/assets/mohammad-yahia.jpg`
- CV PDF: `public/Mohammad_Yahia_CV.pdf`
